## 3. WORKBOOK RECLASSIFICATION SUMMARY

- **Original Workbook Baseline (`references/70-security.xlsx`)**: 70 Controls | P0 = 35, P1 = 24, P2 = 11 | 59 Applicable, 11 Conditional | All 70 = `NON VERIFIE`.
- **Sales AI Reassessment**:
  - Controls elevated from Conditional/P2 to **P0**:
    - `31` (Webhook signature verification) -> P0 (Crucial for Stripe/WhatsApp/Twilio).
    - `32` (Frontend-only payment checks) -> P0 (Financial loss prevention).
    - `39` (Prompt injection) -> P0 (Core AI threat).
    - `40` (AI tools bypassing permissions) -> P0 (Critical agent boundary).
    - `59` (Webhook replay prevention) -> P0 (Financial duplicate-spend defense).
    - `65` (AI sensitive info disclosure) -> P0 (Data exfiltration defense).
    - `66` (Unsafe use of AI output) -> P0 (Commercial claim verification).
    - `67` (Excessive AI agency) -> P0 (Deterministic domain authority invariant).
    - `70` (Unsecured realtime/WebSockets) -> P0 (Voice/chat session security).
  - Controls reclassified as N/A:
    - `18` (NoSQL injection) -> N/A (Relational PostgreSQL + pgvector used exclusively).
- **Proposed Extensions**: 12 new controls (SAI-01 to SAI-12) covering Voice AI identity, anti-spoofing, data retention, multilingual injection, RAG isolation, and typed tool boundaries.
